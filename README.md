# DOMI FORTNITE RADAR — Updates

Windows向けのFortniteニュース帯アプリ「DOMI FORTNITE RADAR」の公式更新配布先です。

最新版は [Releases](https://github.com/indie01games/domi-fortnite-radar-updates/releases/latest) からダウンロードしてください。Python 3.12以上（64bit）が必要です。

初回はZIPを「すべて展開」し、`setup.cmd` → `start.cmd` の順で起動します。セットアップ済みなら `start.cmd` で起動できます。

v0.2.1以降は「アプリの更新」→「最新版を確認」から、ダウンロード・更新・再起動を行えます。旧版に更新機能がない場合は、最初の1回だけ最新版ZIPへ入れ替えてください。ニュース履歴と表示設定は別フォルダーに保存され、引き継ぎます。

更新時にニュース帯は一時的に消えます。OBSとツレモンの設定は変更しません。

この配布先にはアプリ本体と更新情報だけを掲載します。利用者の履歴・設定・認証情報は含みません。
